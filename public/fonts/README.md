# Audrey (display)

Licensed Audrey files belong here. The site prefers them via `@font-face`.

Expected filenames (`.woff2` preferred; `.otf` accepted):

| File | Weight / style |
| --- | --- |
| `Audrey-Regular.woff2` or `Audrey-Regular.otf` | 400–500, roman |
| `Audrey-Medium.woff2` or `Audrey-Medium.otf` | 500–600, roman |
| `Audrey-Italic.woff2` or `Audrey-Italic.otf` | 400–500, italic |

**Until files are present**, `--font-display` uses **Cormorant Garamond** (Google Fonts) as a temporary display face — never Georgia, Times, or Bodoni.
