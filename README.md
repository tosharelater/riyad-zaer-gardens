# Riyad Zaer Gardens

Marketing site (UI only) for **Riyad Zaer Gardens** — mid-standing Moroccan real estate in Rabat / Aïn Aouda.

## Routes

- `/` — cinematic home hero, project pitch, housing-aid callout
- `/services` — Ascenseur, Espaces verts, Sécurité, Parking, Finitions, Aides logement
- `/contact` — WhatsApp CTA + lead form (client-side success toast)

## Brand

- Black `#0A0A0A` · Deep teal `#003B36` · Champagne gold `#C5A367`
- FR / AR language toggle with RTL for Arabic

## Develop

```bash
npm install
npm run dev
npm run build && npm run preview
```

Requires Node.js ≥ 22.12.
